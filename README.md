# MyLibs

## Better output

Библиотека из одного ".h" файла с дефайнами разных цветов и escape-последовательностей.

## error_manage

Библиотека для моих старых проектов для обработки ошибок. Имеет глобальную переменную с возможность юдобавления нескольких ошибок сразу

## helper funcs

Вспомогательные функции для работы с файлами, безопасной реаллокации и free и тд.

## sassert

assert, только с добавлением своего кода ошибки и сообщением. Использует `better output`
